# V5 验收

已逐项查看 zodiac-v5.png 和 planets-v5.png 中全部 22 个符号的 16、24、32px 效果。图中三档样本由当前 SVG 内容经 resvg 直接渲染，以原生像素尺寸展示，不使用字体或另外绘制的预览图形。另附 64px 放大参考。

22 个 SVG 通过 XML 与统一属性检查。66 张实际渲染 PNG 均通过 alpha 包围盒边缘留白检查，未触及画布边界；具体结果见 render-checks.json。已修正天蝎座箭尾、天王星底圆和海王星箭头的边缘留白。

检查了双角、立柱、对置圆环、回环、交叉、箭头、月牙、十字与三叉等各自标准结构；未发现缺失笔画、裁切或非等比拉伸。天王星 H 形和冥王星圆、托弧、十字结构保留。水瓶座折角柔化且两条波线分离，太阳中心点在 16px 下可见。

所有中心线使用统一 1.9 线宽与圆形端点；V4 的 1.8 线宽略增至 1.9，改善小尺寸可见度。16px 下的曲线、斜线仍受正常抗锯齿灰度变化影响，未强制扭曲路径以逐像素对齐。最终显示也取决于屏幕像素密度和浏览器缩放。

原始 22 个 SVG 备份未覆盖；本轮仅修改通用符号库目录。
